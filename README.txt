GOマップ Ver.3 オフラインPWA 試作版

【公開・初回利用】
ZIPを展開して全ファイルを同じフォルダ構成でHTTPS対応サーバー（GitHub Pages等）にアップロードしてください。
ブラウザで index.html にアクセスし、初回はオンラインで全データの読み込みとService Workerのインストール完了を待ってください。
次回以降はオフラインで起動できます。ホーム画面への追加にも対応します。
※ファイルを直接ダブルクリックして開く file:// 方式では動きません。
※初回読み込み直後はキャッシュ保存が完了するまで通信を切らないでください。
※iOSではストレージ削除やOSによるデータ整理でオフラインキャッシュが消える場合があります。

【引継ぎ】
Ver.2の町丁目ポリゴン・道路・鉄道・24時間/4時間/1時間集計・色分け・ランキングを引継ぎ。
外部CDNに依存せずCanvasで描画します。道路と鉄道はVer.2同梱データのためオンライン地図タイルは使いません。
認証・利用期限・アクセス制限なし。

【更新】
データやコードを更新する場合はsw.jsのCACHE文字列を新しい値に変更してください。
